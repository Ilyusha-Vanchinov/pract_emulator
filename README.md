# ПРОВЕРКА РАБОТЫ ЭМУЛЯТОРА

## Этап 1:

Запустите **main.py**. В открывшемся окне введите:

1) `ls` (сработает уже полноценно);
2) `cd /home` (переход в репозиторий);
3) `ls "имя с пробелом"` (проверка парсера);
4) `un_cmd` (проверка ошибки);
5) `exit` (закрытие программы).


## Этап 2:

Запустите в системном терминале: `python main.py --vfs test_vfs.csv --script test_basic.txt`


## Этап 3:

Запустите в системном терминале: `python main.py --vfs deep_vfs.csv --script test_full.txt`
